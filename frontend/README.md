# AI-Fridge — экран «Кладовая»

Мобильная вёрстка главного экрана приложения умного холодильника: сводка по продуктам,
поиск, фильтр по категориям и списки продуктов, сгруппированные по сроку годности.

## Запуск

Сборка и зависимости не нужны — это статическая страница. Достаточно открыть `index.html`
в браузере. Для проверки на телефоне удобнее поднять локальный сервер:

```bash
python -m http.server 5173
```

Затем открыть `http://<ip-компьютера>:5173` на телефоне в той же сети либо
`http://localhost:5173` в режиме эмуляции мобильного устройства в DevTools.

## Структура

| Файл | Назначение |
| --- | --- |
| `index.html` | Разметка экрана и шаблон карточки продукта |
| `styles.css` | Тёмная тема, сетка экрана, компоненты |
| `app.js` | Демо-данные, группировка по сроку годности, поиск и фильтры |

## Что учтено для мобильных

- `viewport-fit=cover` и `env(safe-area-inset-*)` — контент не заходит под «чёлку» и
  системную полосу жестов.
- Контейнер ограничен шириной 430 px и центрируется, поэтому на десктопе экран
  выглядит как на телефоне.
- Все нажимаемые элементы не меньше 36–44 px, отключена подсветка тапа.
- Лента категорий скроллится горизонтально без видимого скроллбара.
- Плавающая кнопка «+» и таб-бар зафиксированы над контентом и учитывают безопасную зону.
- Учитывается `prefers-reduced-motion`.

## Данные

Список продуктов задан массивом `PRODUCTS` в `app.js`. Поле `hoursLeft` — часы до конца
срока годности (отрицательное значение означает просрочку); от него зависят группа
продукта, цвет бейджа и цифры в сводке. Порог для группы «Скоро испортится» задаётся
константой `SOON_THRESHOLD_HOURS` (по умолчанию 96 часов).
